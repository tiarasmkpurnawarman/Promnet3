# Personal Website

Project ini merupakan website pribadi sederhana yang dibuat menggunakan HTML dasar.

Website terdiri dari beberapa halaman:
- Home
- About
- Project
- Contact

## Fitur
- Navigasi antar halaman menggunakan hyperlink
- Menampilkan foto profil
- Menampilkan data diri
- Menampilkan hobi dan riwayat pendidikan
- Menampilkan daftar project
- Menampilkan tabel
- Form kontak sederhana

## Teknologi yang Digunakan
- HTML5
